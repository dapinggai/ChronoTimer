ChronoTimer 更新说明
版本：1.3.4（2026-11-13）
作者：灵灵漆

一、本次更新概述
新增 3 个筛选选项，解决两类无用计时条：
1) 进食、饮水产生的 Buff 也出条；
2) 别人给你的 Buff（王者祝福、智慧祝福等）也出条。

二、新增选项（位置：设置 → 常规 → 查看监控名单 下方）

1. 只显示自己施加的 Buff（默认关闭）
   · 只保留自己施放的 Buff，宠物、召唤物、图腾施放的也算自己。
   · 别人给的王者祝福、智慧祝福、爪子、耐力等会被过滤。
   · 原理：监听 Nampower 的 AURA_CAST_ON_SELF 事件记录光环来源。
   · 插件会自动尝试开启 NP_EnableAuraCastEvents。
   · 安全保护：如果完全收不到该事件，此选项自动失效，不会把所有 Buff 都隐藏。
   · 注意：登录前已存在、之后没有重新施放的 Buff 没有来源记录，
     开启后不显示，重新施放一次即可恢复。

2. 忽略食物 / 饮水 Buff（默认开启）
   · 按图标与名称特征过滤：INV_Drink / INV_Misc_Food 图标，
     以及名称含 食物、饮水、进食、饱食、food、drink 的光环。
   · 吃喝不再产生计时条。
   · 自定义食物若未被识别，把名字（或其中一段）加进「忽略名单」即可。

3. 忽略名单（文本框）
   · 按名称包含匹配，不区分大小写，多个关键词用 , ; 、 或换行分隔。
   · 示例：王者, 智慧, 食物, 饮水
   · 优先级高于「监控名单」：同时命中时以忽略为准。
   · 对自身 Buff / Debuff 与目标身上的 Debuff 同时生效。

三、行为说明
· 三个选项改动后立即生效，会马上清掉当前不符合条件的计时条。
· 过滤统一在显示判断处执行，白名单、忽略名单、来源过滤、吃喝过滤互不冲突。
· 图腾计时不受这些过滤影响，仍由「显示图腾」开关控制。
· 与已有功能兼容：最短 / 最长显示时长、多彩配色、职业配色、层数显示均不变。

四、文档同步
· 使用说明.md：更新功能一览、常规设置表、监控名单与忽略名单章节、常见问题。
· 使用说明.txt：同步以上内容（新增第 5 步「过滤不想要的光环」，原步骤顺延）。

五、升级注意事项
· 旧配置自动兼容，新增选项会使用默认值，无需删除 SavedVariables。
· 若更新后仍看到个别不需要的 Buff，优先用「忽略名单」补充关键词。

========================================
版本：1.4.7（2026-11-13）
作者：灵灵漆
========================================

一、本次更新概述
图标模式下的居中控制类 Debuff（CC）显示优化：
1) 中央 CC 图标上方横线上方显示技能名称；
2) 修复技能名称、倒计时数字、层数全部不显示的问题；
3) 泛光效果重写，修复拉伸后只有两端发光的问题；
4) 新增 CC 关键词：冰冻陷阱、破胆怒吼。

二、详细改动

1. 中央 CC 图标显示技能名称
   · 技能名称显示在中央 CC 图标上方的横线上方。
   · 字号增大（图标尺寸 × 0.30，最小 12 号），颜色改为白色带黑色描边。
   · 使用独立的 TOOLTIP 高层 frame 承载，确保不被任何 backdrop 或图标遮挡。

2. 修复文字全部不显示的问题
   · 原因：pfUI 的 RobotoMono.ttf 字体文件不存在，SetFont 静默失败，
     导致技能名称、倒计时数字、层数等所有文字均不可见。
   · 修复：GetFontPath 不再使用 pfUI 自定义字体，改用游戏自带字体
     （GameFontNormal，兜底 Fonts\FRIZQT__.TTF）。

3. 泛光效果重写
   · 原因：原使用 UI-ActionButton-Border 边框贴图，该贴图中间透明、
     只有边缘发光，拉伸为长条后只有左右两端有光，中间为空。
   · 修复：改用纯色矩形（鲜红）+ SetGradientAlpha 垂直渐变淡出，
     靠近横线处最亮，向外渐隐，整条横线上方均为实心红色光带。
   · 保留 ADD 混合模式与呼吸动画。

4. 新增 CC 关键词
   · 中文：冰冻陷阱、破胆怒吼
   · 英文：intimidating shout
   · 以上技能触发时会在屏幕中央以 CC 图标形式显示并标注技能名称。

三、文档同步
· 使用说明.md / 使用说明.txt：版本号同步 1.4.7。

四、升级注意事项
· 若中了控制技能但未在中央显示，请确认「设置 → 图标模式 → 控制类 Debuff 居中显示」已开启。
· 若仍有控制技能未被识别，可反馈技能名称，后续补充关键词。

========================================
版本：1.4.8（2026-11-14）
作者：灵灵漆
========================================

一、本次更新概述
1) 监控名单 / 忽略名单 支持填写法术 ID；
2) 新增玩家目标 PvP 控制递减估算，修正冰冻陷阱等控制时长；
3) 加载改为静默，新增 /ct status 诊断，修复个别环境下打不开设置的问题。

二、详细改动

1. 名单支持法术 ID（名称、ID 都可用）
   · 监控名单：名称或纯数字 ID，例如「切割, 破甲, 172」。
   · 忽略名单：名称关键词或纯数字 ID，例如「王者, 智慧, 172」。
   · 规则：纯数字按法术 ID 精确匹配；非数字按名称处理
     （监控名单要求名称一致，忽略名单按包含匹配、不区分大小写）。
   · /ct list 名单面板中，填 ID 的行会显示解析出的技能名，如「寒冰箭 (116)」。
   · 自身 Buff / Debuff 与目标身上的 Debuff 同时生效。

2. PvP 控制递减估算（设置 → 常规 → 显示目标身上的 Debuff 下方）
   · 新增开关「PvP 控制按递减估算」，默认开启，仅对玩家目标生效。
   · 递减窗口 18 秒，倍率 100% → 50% → 25% → 免疫。
   · 瘫痪类（羊、闷棍、凿击、冰冻陷阱、忏悔、翼龙钉刺等）共享递减，
     在原有类别上补齐了冰冻陷阱 / 冰霜陷阱 / 忏悔 / 翼龙钉刺。
   · 冰冻陷阱在 PvP 中对玩家目标按 10 秒上限计算（乌龟服软上限）。
   · 同一法术按效果多次触发事件时做 0.2 秒去重，避免递减被重复累加。
   · 心跳挣脱是随机判定、不进递减，无法预测：计时条显示的是上限，
     光环消失（心跳挣脱、伤害破冰、章解、抵抗）后计时条会在 1 秒内结束。

3. 加载与设置入口修复
   · 正常加载时不再输出任何聊天信息，只有出问题才提示。
   · 命令提前注册：即使依赖库缺失或 UI 创建失败，/ct、/chron、/chronometer
     仍可用并给出明确提示；新增 /ct status 输出诊断信息。
   · 小地图按钮、计时条分组、设置面板改为分步容错，单步失败不再中断初始化。
   · 兼容 1.12 客户端没有 Button:RegisterForClicks 的情况。
   · PLAYER_ENTERING_WORLD 时若尚未初始化成功会再尝试一次。

三、文档同步
· 使用说明.md / 使用说明.txt：名单填写说明补充法术 ID；
  新增「PvP 控制按递减估算」章节与选项说明；版本号同步 1.4.8。

四、升级注意事项
· 旧配置自动兼容，新增选项使用默认值，无需删除 SavedVariables。
· 若发现 PvP 控制时长被“砍两次”（服务器已下发递减后的时长），
  关闭「PvP 控制按递减估算」即可直接采用服务端时长。
· 小地图按钮可被 MinimapButtonCollector 正常收纳，点击仍打开设置。

========================================
版本：1.5.0（2026-11-14）
作者：灵灵漆
========================================

一、本次更新概述
完整内置 ArchiTotem 图腾大师，整合为一个插件，仅需启用 ChronoTimer。

二、详细改动

1. 内置 ArchiTotem 全套功能
   · 四系图腾条（土 / 火 / 水 / 风），支持弹出按钮、点击直接施放。
   · 一键召唤所有图腾、图腾召回、图腾掌握天赋自动识别。
   · 预设组合：PVE / PVP / 抗性 / 自定义，支持预设管理界面。
   · 图腾冷却数字、鼠标提示、拖拽手柄、位置与缩放保存。
   · 按键绑定：一键召唤、召回、四系单独召唤、跳过切换、四种预设召唤。

2. 文件与加载整合
   · ArchiTotem 全部文件放入 ChronoTimer\ArchiTotem\ 子目录，
     由 ChronoTimer.toc 统一加载，不再作为独立插件出现在插件列表。
   · 配置变量 ArchiTotem_Options 并入 ChronoTimer 的 SavedVariables。
   · 内部贴图路径已重定向到 ChronoTimer\ArchiTotem，避免丢图。
   · 版本/作者元数据改为内置常量，不依赖独立插件信息。

3. 命令
   · 新增 /ct totem（或 /ct 图腾）查看图腾助手帮助。
   · 原有 /at、/architotem 命令保持可用。

4. pfUI 适配
   · 检测到 pfUI 时，图腾按钮改用 pfUI 扁平边框，隐藏暴雪立体边框。
   · 图标做边缘裁切，按钮文字 / 冷却数字 / 剩余时间统一为同款字体与字号。
   · 图腾组合管理窗口、覆盖详情窗口同步套用 pfUI 边框。
   · pfUI 加载晚于本插件时会自动延迟检测并补做美化，无需手动 /reload。

三、升级注意事项
· 独立版 ArchiTotem 已在 AddOns 中改名为 ArchiTotem.disabled 停用，
  如需恢复，把文件夹名改回 ArchiTotem 即可（两者不要同时启用，
  否则会出现两套图腾条）。
· 由于插件名变更，旧的角色独立配置不会自动迁移；
  首次进入可在 /ct totem 中重新设置，或使用默认配置。
· 非萨满职业不会加载图腾模块，其余光环计时功能不受影响。

   · 按住 Ctrl + 左键拖动面板可移动位置，松开后自动保存。

========================================
版本：1.6.27（2026-11-27）
作者：灵灵漆
========================================

一、配置改为按角色独立保存
· toc 中 `SavedVariables` 改为 `SavedVariablesPerCharacter`，`ChronoTimerDB` 按角色存储。
· 同一账号下不同角色的设置互不影响，调整一个角色不再改动其他角色。
· 存档位置从 `WTF\Account\<账号>\SavedVariables\ChronoTimer.lua` 变为
  `WTF\Account\<账号>\<服务器>\<角色>\SavedVariables\ChronoTimer.lua`。
· 注意：旧的账号级存档不会自动迁移，各角色首次上线使用默认配置；
  如需保留原设置，手动把旧的账号级 `ChronoTimer.lua` 复制到对应角色目录下即可。

二、移除内置图腾助手，仅保留图腾计时
· 剔除完整内置的 ArchiTotem 图腾大师（四系图腾条 / 一键召唤 / 召回 / 预设 / 外观配置），
  删除 ChronoTimer\ArchiTotem\ 整个目录及 toc 中的全部加载项，不再随插件加载。
· 设置面板移除「启用一键图腾（ArchiTotem）」开关、ArchiTotem 命令帮助按钮与整个
  「图腾栏」外观配置分类；移除 /ct totem 命令与独立 ArchiTotem 冲突检测弹窗。
· 图腾计时功能完全保留：萨满页的「显示图腾」开关仍正常工作，倒计时、常驻图腾、
  图腾召回清除等逻辑不变。

三、图腾计时改为不依赖 ArchiTotem 数据
· 时长改以内置图腾表（TOTEM_INFO）为准，不再读取 ArchiTotem_TotemData。
· 图腾掌握天赋（+20% 持续时间）改为计时模块自行扫描天赋检测（CT.UpdateTotemicMasteryBonus），
  登录时与天赋变更后自动刷新，不再依赖 ArchiTotem_TotemicMasteryBonus 全局变量。

四、存档
· toc 的 SavedVariablesPerCharacter 仅保留 ChronoTimerDB，移除 ArchiTotem_Options。
· 旧角色存档里残留的 enableArchiTotem / ArchiTotem_Options 字段不再被读取，无害；
  如需彻底清理，删除对应角色目录下的 ChronoTimer.lua 后重新配置即可。

五、升级注意事项
· 覆盖全部文件后 /reload 即可。原本依赖图腾助手一键召唤的玩家，请改用独立图腾插件
  （如 ArchiTotem 单独启用）或系统动作条，计时条侧不受影响。
