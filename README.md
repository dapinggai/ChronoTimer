# ChronoTimer 使用说明

适用于《乌龟服》(Turtle WoW) 1.12 客户端。ChronoTimer 基于 Chronometer 重构，用来显示自身 Buff / Debuff、图腾、多目标 HoT / DoT 以及团队共享火焰易伤的剩余时间。

- 版本：1.6.25
- 作者：灵灵漆
- 仓库：https://github.com/dapinggai/ChronoTimer
- 原作：Chronometer（原作者 Bhattu，后续修复 laytya、dein0s、武藤纯子酱、Sunelegy）
- 依赖：`!Libs`（内含 CandyBar-2.2、Waterfall-1.0 等库）；名称识别、多目标 HoT / DoT 与火焰易伤追踪依赖 Nampower

---

## 一、安装

1. 把 `ChronoTimer` 整个文件夹放到：
   `World of Warcraft\Interface\AddOns\ChronoTimer`
2. 确认目录结构为：
   ```
   Interface\AddOns\ChronoTimer\ChronoTimer.toc
   Interface\AddOns\ChronoTimer\ChronoTimer.lua
   Interface\AddOns\ChronoTimer\IconMode.lua
   Interface\AddOns\ChronoTimer\Textures\...
   ```
3. 确认 `Interface\AddOns\!Libs` 已安装并启用。
4. 进入游戏，在角色选择界面勾选 `ChronoTimer`，或在聊天框输入 `/reload`。

## 二、功能一览

- 自身 Buff / Debuff 倒计时，支持叠加层数（从锚点向下依次排开）
- 图腾剩余时间（萨满，支持一键施放；常驻图腾显示「常驻」且不显示倒计时）
- 盗贼剑刃乱舞常驻监控（持续到取消的 Buff，显示「常驻」标签、无倒计时，可独立开关）
- 多目标 DoT / Debuff：按目标 GUID 独立计时，切换目标不消失，目标死亡、驱散或自然结束后移除
- 多目标 HoT：切换目标后持续显示光环所在目标名，左键点击计时条或图标可直接对原目标补施同等级技能
- 团队共享火焰易伤：30 秒、最多 5 层，跟踪团队叠加与刷新
- 图标上直接显示叠加层数（如破甲、火焰易伤 5 层）
- Buff / Debuff 多彩配色，一眼区分增益与减益
- 计时条框体与锚点框架按职业配色
- 来源过滤：只显示自己（含宠物）施放的 Buff，别人给的祝福不再计时
- 自动忽略食物 / 饮水 Buff，吃喝不再读条
- 自定义监控名单：只显示你关心的 Buff / Debuff
- 忽略名单：按名称关键词排除不需要监控的光环
- 监控名单查看面板：实时查看名单中每个光环的计时状态
- 最短 / 最长时长过滤、锚点拖动、小地图按钮
- 图标模式：WeakAuras 风格的图标 + 倒计时，可自由调整图标大小、间距与位置
- 控制类 Debuff 居中：自身眩晕、定身等单独显示在屏幕中央，图标上下带红色横杠（条形与图标模式都会显示）
- 盗贼 / 德鲁伊能量与连击点显示：能量条 + 连击点小长条，可设置仅战斗中显示
- 盗贼割裂时长自动换算：连击点（8～16 秒）叠加「血腥气息」天赋（1 级 +4 秒、2 级 +6 秒）
- 盗贼肾击时长自动换算：1 秒 + 1 秒 × 连击点（5 星 = 6 秒）

### 2. 监控名单与忽略名单

**监控名单（白名单）**

在「监控名单」文本框中填写名称或法术 ID，多个用 `,` `;` `、` 或换行分隔，例如：

```
切割, 破甲, 撕裂, 172
```

注意：

- 名称必须与游戏内显示的名称一致（英文名称不区分大小写）
- 纯数字按**法术 ID** 精确匹配（适合名称带特殊字符、多语言或同名技能）
- 开启「仅监控自定义名单」后名单才生效
- 名单面板里绿色表示正在计时，灰色表示当前未激活
- 多目标 HoT / DoT 需要收到 Nampower 施法或光环事件才开始计时；计时建立后切换目标不会清除

**忽略名单（黑名单）**

用来排除不想看到的 Buff / Debuff，可填**名称关键词**或**法术 ID**，多个用 `,` `;` `、` 或换行分隔，例如：

```
王者, 智慧, 食物, 172
```

- 名称按包含匹配（不区分大小写）；纯数字按法术 ID 精确匹配
- 只要光环名称里包含其中任意关键词，就不会显示计时条
- 优先级高于「监控名单」：同时命中时以忽略为准
- 目标 Debuff 同样受「忽略名单」影响
- 常见用法：`王者,智慧,力量,庇护` 过滤骑士祝福类；`食物,饮水,进食` 过滤吃喝

**只显示自己施加的 Buff**

开启后只保留自己（含宠物、召唤物、图腾）施放的 Buff，别人给你的祝福会直接过滤。说明：

- 依赖 Nampower 的 Aura Cast 事件，插件会自动尝试开启 `NP_EnableAuraCastEvents`
- 若完全收不到该事件，本选项会自动失效，避免把所有 Buff 都隐藏
- 登录前就已存在、之后没再被施放的 Buff 没有来源记录，开启过滤后不会显示，重新施放一次即可恢复

**PvP 控制按递减估算**

只对**玩家目标**身上的控制类 Debuff 生效（羊、闷棍、凿击、冰冻陷阱、忏悔、恐惧、定身、昏迷等）：

- 递减窗口 18 秒，倍率 100% → 50% → 25% → 免疫，ESC 徽章解控后从解控瞬间开始重新计时
- 香草瘫痪类还有**心跳挣脱**：第一次无递减也可能提前醒，且不进递减。计时条显示的是上限，光环消失时计时条会结束
- 任何伤害打破控制效果后，光环移除事件或周期扫描会清理计时

### 3. 多目标 HoT / DoT 与火焰易伤

- 同一种 HoT 或 DoT 可同时存在于多个目标上，插件用「目标 GUID + 法术 ID」分别保存，不再互相覆盖。
- 切换当前目标不会清除已有计时；目标死亡、光环被移除、驱散或自然到期后清理。暂时无法查询到原目标时保留到自然到期，避免误删。
- HoT 计时条显示光环所在目标名称；图标模式下仅 HoT / DoT 图标下方显示目标名称，其他图标不显示下方文字。开启「点击补 HoT」后，左键点击会使用 `CastSpellByName(技能完整名称, 原目标GUID)` 补施，不需要切换或恢复目标。
- 点击本身和读条开始都不会重置计时；收到施法成功事件后才重置，因此瞬发和读条 HoT 使用同一规则，读条取消也不会提前刷新。
- 火焰易伤（22959）持续 30 秒、最多 5 层，是团队共享 Debuff，新增层数不限制施法者。自己的 3/3 强化灼烧或火焰冲击命中已叠满 5 层的目标时，会按成功施法续 30 秒。
- 1.12 无法读取其他单位光环的真实剩余时间，显示值由 Nampower 事件与法术时长推算；其他法师造成的满层同层刷新若客户端没有事件，插件无法可靠续时，最终以光环新增、移除和周期扫描修正。

## 五、颜色说明

- **填充色**：Buff 使用冷色 / 生机色（翠绿、天蓝、青绿、金黄等），Debuff 使用暖色 / 警示色（红、橙、品红、紫等），同一法术颜色固定不跳变
- **框体色**：开启「职业配色（框架）」后，自身相关计时条的框体背景、拖动摇点使用你的职业色；目标 Debuff 的框体使用目标职业色
- **层数**：叠加层数大于 1 时，数字直接显示在计时条左侧图标上；层数回到 1 时自动隐藏

## 六、常见问题

**Q：计时条不显示？**
1. 确认「启用计时」已勾选；
2. 检查「最短 / 最长显示时长」是否把该光环过滤掉了；
3. 若开启了「仅监控自定义名单」，确认名称已填写且与游戏内一致；
4. 检查是否命中「忽略名单」，或被「只显示自己施加的 Buff」「忽略食物 / 饮水 Buff」挡掉；
5. 多目标 HoT / DoT 需要 Nampower；若切换目标前从未建立计时，请先成功施放一次。已建立的计时不应因切换目标消失。

**Q：别人给我的王者祝福、智慧祝福也出现了计时条，怎么过滤？**
三种办法，任选其一：
1. 开启「只显示自己施加的 Buff」——只保留自己施放的 Buff；
2. 在「忽略名单」里填 `王者,智慧`（名称包含即忽略）；
3. 把「最长显示时长」调小（例如 300 秒），长时间祝福会被过滤。

**Q：吃喝（进食 / 饮水）也会出现计时条？**
默认已开启「忽略食物 / 饮水 Buff」，会按图标与名称特征过滤。若某个自定义食物没被识别，把它的名字或其中一段（例如 `烤肉`）加入「忽略名单」即可。

**Q：光环名称显示为「法术 xxxx」或不准？**
说明没有检测到 Nampower，安装并启用 Nampower 后名称、图标、多目标 HoT / DoT 与火焰易伤追踪才完整。

**Q：破甲满 5 层后再打，层数会消失吗？**
不会。刷新时会沿用上次记录的层数，图标上仍显示 5。

**Q：图腾计时和监控名单冲突吗？**
不冲突。监控名单只影响 Buff / Debuff，图腾计时始终按「显示图腾」开关工作；常驻图腾会显示「常驻」标签，不做倒计时。图腾被新盖掉或使用「图腾召回」后会立即消失。

**Q：萨满一键施放图腾不显示？**
确认已开启「显示图腾」并安装了 Nampower。插件会通过 Nampower 的施法事件识别一键施放的四个图腾，再与游戏图腾接口互相校验；若图腾接口本身不返回持续时间，则显示为「常驻」。

**Q：锚点和计时条重叠 / 位置乱？**
点击「重置位置」恢复默认，再用「显示/隐藏拖动锚点」重新拖动即可。自身 Buff 向下、目标 Debuff 向上，两者以锚点为分界，不会互相重叠。

**Q：想恢复默认设置？**
退出游戏后删除 `World of Warcraft\WTF\Account\<账号>\SavedVariables\ChronoTimer.lua`，或在设置中逐项调整。

**Q：开启了图标模式，但屏幕上没有图标？**
1. 确认「使用图标显示」已勾选，且「显示 Buff」「显示 Debuff」（常规）与「显示图腾」（萨满页）处于开启状态；
2. 在图标模式里点「解锁图标位置」，检查图标列是否被拖到屏幕外，可点「重置图标位置」；
3. 有控类 Debuff 时，它会从图标列移到屏幕中央，检查「解锁居中图标位置」是否把它拖出了屏幕。
