ChronoTimer 光环计时  v1.6.24
作者：灵灵漆
原作：Chronometer（原作者 Bhattu，后续修复 laytya、dein0s、武藤纯子酱、Sunelegy）
适用于《乌龟服》(Turtle WoW) 1.12，需要 !Libs，建议安装 Nampower。

【安装】
把 ChronoTimer 和 !Libs 放进 Interface\AddOns\，进游戏勾选后 /reload。

【使用方法】
1. 打开设置
   聊天框输入 /ct，或点小地图按钮。

2. 调整位置
   设置 → 计时条 → 勾选「显示拖动锚点」，拖动锚点摆好位置后取消勾选。
   自身 Buff / Debuff / 图腾从锚点向下排，多目标 HoT / DoT / Debuff 向上排。
   「重置位置」可恢复默认。

3. 选择要显示的内容
   常规 → 勾选「显示 Buff」「显示 Debuff」；萨满勾选「显示图腾」。
   盗贼默认开启「监控剑刃乱舞」：该 Buff 持续到取消、无剩余时间，
   激活时显示「常驻」计时条 / 图标（无倒计时），取消后自动隐藏。
   可设置「最短 / 最长显示时长」过滤过短或过长的光环，
   例如最长填 300，长时间祝福就不会占屏。

4. 只监控自己关心的光环（可选）
   常规 → 勾选「仅监控自定义名单」，在「监控名单」里填名称或法术 ID，
   逗号、分号、顿号或换行分隔，例如：
       切割, 破甲, 撕裂, 172
   名称要与游戏内一致（英文不区分大小写）；纯数字按法术 ID 精确匹配。
   填写后其余光环不再显示。

5. 过滤不想要的光环（可选）
   · 忽略名单：填名称关键词或法术 ID，逗号分隔，例如：
         王者, 智慧, 食物, 172
     名称按包含匹配（不区分大小写），纯数字按法术 ID 精确匹配；
     优先级高于「监控名单」，对目标身上的 Debuff 同样生效。
   · 只显示自己施加的 Buff：只保留自己（含宠物、召唤物、图腾）施放的
     Buff，别人给的王者祝福、智慧祝福等不再显示（需要 Nampower 的光环
     施法事件；若完全收不到该事件，此选项会自动失效）。
   · 忽略食物 / 饮水 Buff：默认开启，吃喝产生的 Buff 不再显示计时条。

6. 查看监控状态
   设置 → 常规 → 查看监控名单，或输入 /ct list。
   绿色 = 正在计时并显示剩余秒数，灰色 = 未激活。

7. 多目标 HoT / DoT / Debuff 与火焰易伤
   常规 → 勾选「显示多目标 DoT / Debuff」，对敌人成功施加后出现。
   同一种 DoT 可在多个敌人身上分别计时，切换目标不会清除；
   持续到自然结束，目标死亡、被驱散或光环移除时清理。
   勾选「跟踪友方 HoT」后，自己施加的周期治疗也会在切换目标后继续显示，
   计时条与图标下方显示光环所在目标名称。
   开启「点击补 HoT」后，左键点击 HoT 计时条或图标可直接对原目标补施
   同等级技能，不切换当前目标。点击和读条开始都不重置计时，
   收到施法成功事件后才重新计时；读条取消不会提前刷新。
   勾选「跟踪火焰易伤」可显示强化灼烧的团队共享 Debuff（法术 ID 22959）：
   持续 30 秒、最多 5 层，新增层数不限制施法者；自己的 3/3 强化灼烧
   或火焰冲击命中满 5 层目标时续 30 秒。其他法师的满层同层刷新若客户端
   没有事件则无法可靠推算，以实际光环事件和周期扫描修正。
   对玩家目标，勾选「PvP 控制按递减估算」后，控制类 Debuff 按 18 秒递减
   计算（100% → 50% → 25% → 免疫）；香草瘫痪类有“心跳挣脱”，
   第一次也可能提前醒，计时条显示的是上限。
   文字内容支持 $s（法术名）、$n（层数）、$t（目标名）。

8. 能量 / 连击点（盗贼 / 德鲁伊）
   仅盗贼与德鲁伊（猎豹等能量形态）生效，其他职业不显示该分类。
   设置 → 能量/连击点：可分别关闭能量条或连击点小长条。
   勾选「仅战斗中显示」后，能量条与连击点只在进入战斗时出现，
   脱战自动隐藏，回能光标在下一次战斗中重新校准
   （默认关闭，即始终显示）。
   还可调整能量条材质、宽度 / 高度、连击点高度 / 间距，
   以及「连击点样式」（长条 / 正方形 / 菱形 / 圆形，后三者在能量条上方居中），
   以及回能光标开关；「移动位置（解锁拖动）」点一下出现绿框，
   左键拖好后再点一次锁定，平时也可按住 Ctrl 拖动；
   「恢复默认位置」回到屏幕中下方。

9. 颜色与外观
   计时条 →「多彩颜色」：Buff 冷色、Debuff 暖色，自动分色；
   「职业配色（框架）」：框体按职业着色，不影响 Buff 填充色；
   还可以调宽度、高度、间距、缩放、材质、反向填充和淡出时间。

10. 图标模式（WeakAuras 风格）
   设置 → 图标模式 → 勾选「使用图标显示」，计时条会切换成图标 + 倒计时。
   图标横向排列，每行数量可自定义（默认 8），超过自动换行；
   自身 Buff / Debuff / 图腾向下生长，多目标 HoT / DoT / Debuff 向上生长，方向与计时条一致。
   仅 HoT / DoT 图标下方显示目标名，其他图标不显示下方文字；
   HoT 图标在锁定状态且开启「点击补 HoT」时可左键补施。
   检测到 pfUI 时会自动套用 pfUI 的扁平细边框和像素字体样式。
   自身 Debuff 的图标四周会描红，目标身上的 Debuff 保持深灰边框。
   图标大小、图标间距、每行图标数量都可以自己调；倒计时文字大小可单独调，
   也可以切换为「以整秒显示」（关闭时 60 秒以上显示分:秒，10 秒内显示一位小数）；
   「解锁图标位置」拖好位置后再点一次锁定，
   「重置图标位置」恢复默认。
   勾选「控制类 Debuff 居中显示」后，自身眩晕、定身等控制类 Debuff 会单独
   显示在屏幕中央（条形与图标模式都会显示），图标上下各一条灰色横线，长度约为图标的 2 倍，
   上方横线处显示技能名称（如：眩晕、定身、魅惑），
   横线外有与横线等长的鲜艳红色柔光（带轻微呼吸效果），不显示红框；
   可调整居中图标大小，也能解锁拖动，
   并用「重置居中图标位置」恢复默认。

11. 层数
   有叠层的光环（如破甲、火焰易伤）层数大于 1 时，数字直接显示在图标上。
   火焰易伤为团队共享层数，不要求每层都由自己施加。

【命令】
/ct          打开设置
/ct list     查看监控名单

【提示】
· Buff / Debuff 名称需要 Nampower 才能准确识别；多目标 HoT / DoT 与火焰易伤也依赖 Nampower
· 多目标光环在首次成功施法后建立计时；建立后切换目标不会消失
· 图腾支持一键施放识别，常驻图腾显示「常驻」且无倒计时
· 别人给的祝福不想显示：开启「只显示自己施加的 Buff」，或在「忽略名单」填 王者,智慧
· 吃喝经常读条：确认「忽略食物 / 饮水 Buff」已开启；个别食物没被识别就把它加进忽略名单
· 登录前已有、之后没再施放的 Buff 没有来源记录，开启来源过滤后需重新施放一次才会显示
· 盗贼割裂的剩余时间按连击点（8～16 秒）自动换算，并叠加「血腥气息」天赋（1 级 +4 秒、2 级 +6 秒）
· 盗贼肾击的剩余时间按 1 秒 + 1 秒 × 连击点显示（5 星 = 6 秒）
· 计时条模式下，自身 Debuff 的背景固定为暗红，和 Buff、目标 Debuff 区分
· 想清空配置，删除 WTF\Account\<账号>\SavedVariables\ChronoTimer.lua
